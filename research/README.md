# Research

Cross-project research and capability analysis. Findings here inform ADRs in `../decisions/` and updates to `../architecture/`.

## Scope

- Capability extraction across the existing ecosystem (Jellyfin, Sonarr, Radarr, Prowlarr, AIOStreams, Torrentio, Comet, MediaFusion, Decypharr, NZBDAV, AltMount, Dispatcharr, Threadfin, and others).
- Overlap and duplication analysis across projects.
- Identification of ecosystem workarounds vs. intrinsic capabilities.
- Reusable implementation patterns.

## Per-project analyses

Detailed per-project analyses live in `../projects/` (one file per project). This directory holds cross-cutting research that spans multiple projects.

## Rules

- Label claims as **confirmed** (verified against source), **assumption**, or **open question**.
- Cite the source file/line for confirmed claims.
- Do not state how a project works without inspecting its actual source code.
