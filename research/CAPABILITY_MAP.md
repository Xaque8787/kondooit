# Kondooit Capability Map

## Purpose

This document will eventually map the underlying capabilities discovered across the media ecosystem, deduplicated and compared across projects. It is **not** a list of applications — it is a map of what the ecosystem actually does, independent of which project does it.

The actual map must emerge from repository research. The categories below are provisional placeholders, not assertions.
