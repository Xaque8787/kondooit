# Kondooit Cross-Project Entity Map

## Purpose

Compare domain concepts across existing projects to identify where different projects use different names for the same concept, the same name for different concepts, and which concepts should remain separate in Kondooit.

This document does **not** finalize the Kondooit domain model. It records what was discovered so that the eventual model can be designed from evidence.
